# Terraria 数据目录

- `data/worlds/`：世界文件
- `data/tshock/`：TShock 配置、账号和数据库
- `data/plugins/`：TShock 插件
- `backups/terraria-latest.tar.gz`：总控创建的最新备份

这些目录会在网页首次启动 Terraria 时自动创建。

Terraria 是本仓库最轻的游戏：8 人中型世界大约 0.5–2 GB 内存（常见约 1 GB），CPU 1–2 核即可。Docker 镜像约 0.5–1 GB，世界文件约 50–400 MB。可以与任意一个大型服（Minecraft、幻兽帕鲁或 Project Zomboid）同时运行。
